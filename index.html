AI 设置

默认走本机 OpenCode 反代：http://127.0.0.1:8767/v1/chat/completions，Key 填 local 即可，不需要自己的 API Key。请用“启动刷题器.bat”打开，代理会自动启动。也可以在这里改成 OpenAI/DeepSeek 等外部接口。

如果浏览器提示 CORS 或网络错误，说明该接口不允许网页直连；可以改用支持浏览器调用的接口，或把题目复制到聊天框里问。
